# Template 1 — Skill Spotlight
# Angle   : Targeted skill fluency and practice progression
# Best For: Drills, remediation worksheets, fluency builders, targeted skill practice
# Selects : When the worksheet's core value is focused, structured practice on one skill

---

## Template Selection Criteria

Use this template when:
- The worksheet targets one specific, nameable skill
- The primary teacher motivation is "my students need more practice on [skill]"
- The worksheet is not primarily marketed as multi-level or zero-prep
- No other template is a stronger fit

Default template when no other criteria match.
