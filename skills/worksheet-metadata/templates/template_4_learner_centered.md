# Template 4 — Learner-Centered Brief
# Angle   : Differentiated access to one shared grade-level standard
# Best For: Inclusion classrooms, ELL materials, RTI/MTSS tiers, gifted extensions,
#           co-taught classes, multi-level resource packs
# Selects : When the worksheet comes in multiple versions (leveled) and the primary
#           teacher motivation is "this needs to work for everyone in my room"

---

## Template Selection Criteria

Use this template when:
- The worksheet includes 2 or more differentiated versions of the same content
- The listing targets inclusion, special education, or ELL teachers
- The primary teacher motivation is reaching multiple learner populations at once
- Key search terms include: differentiated, leveled, scaffolded, ELL, IEP-friendly

### SECTION 3 — Three Levels, One Standard
[AGENT: Describe each level specifically. Name the scaffolds, task types, and
cognitive demands for each. The key framing principle is: the standard does not
change across levels, only the access point does. Make this explicit.]

All three versions target `[Standard Code]`. The scaffold changes — the standard
does not.

**Level 1 — Scaffolded Access**
For students [below grade level, ELL at WIDA Level [N]–[N], or receiving Tier 2
or Tier 3 intervention]. Includes [specific scaffold, e.g., "a word bank, sentence
frames for written responses, and a labeled visual model"]. Students demonstrate
[Standard Code] by [simplified task description — same cognitive goal, reduced
language demand, e.g., "selecting evidence from a highlighted passage rather than
locating it independently"].

**Level 2 — On Grade Level**
The core version. Students work with [grade-appropriate text, data set, or problem]
and demonstrate [Standard Code] through [standard task description, e.g., "short-
answer questions requiring them to quote the text and explain their reasoning"].
[N] problems with [brief description of task structure].

**Level 3 — Extended Challenge**
For students exceeding grade level or identified as gifted. Removes scaffolding and
adds [higher-order demand, e.g., "an open-ended synthesis task, a cross-text
comparison, or a real-world application problem"]. Targets [Standard Code] at
[Bloom's level, e.g., "Evaluate and Create"] rather than [Level 2 Bloom's level].

All three versions use the same page layout and visual design. Students seated
next to one another cannot identify which version they have received.

### SECTION 5 — Classroom Contexts
[AGENT: List the classroom structures where this worksheet is most useful.

This worksheet works across a wide range of instructional contexts:

- **Inclusion classrooms** with mixed IEP and non-IEP populations — all students
  receive a version of the worksheet; differentiation is invisible to peers
- **Co-taught classes** — each teacher can distribute and support a separate level
  during independent work time
- **ELL students** at [WIDA / ELPA21 proficiency Level N–N] and above —
  Level 1 sentence frames and word bank reduce language barrier without
  reducing cognitive demand
- **RTI/MTSS Tier 2 small groups** targeting [Standard Code] — Level 1 provides
  the targeted support tier without requiring a separate resource
- **Gifted pullout groups** — Level 3 extends the standard to [higher-order demand]
  without advancing to the next grade's standards

### SECTION 6 — Shared Debrief
[AGENT: Explain how the teacher runs a whole-class debrief after all three levels
have been completed. This is a practical, credibility-building detail that teachers
in inclusion settings need to hear before purchasing.]

Because all three levels share the same standard and the same core question type,
whole-class debrief works without ability-grouping the discussion. Use the Level 2
answer key as the anchor for class conversation — Level 1 and Level 3 responses
map directly onto the same correct-answer criteria. Students at each level can
share their reasoning; the teacher connects responses back to `[Standard Code]`
without revealing which version each student completed.

Universal Design for Learning (UDL), the instructional framework codified in IDEA
2004 reauthorization guidance and adopted as policy in [N] states, requires that
materials provide multiple means of representation and engagement for all learners.
CAST research (2018) demonstrates that differentiated access to the same grade-level

term outcomes for students with learning differences, ELL students, and students in
general education alike. `[Standard Code]` is achievable at all three levels
represented in this worksheet; the scaffold changes, the standard does not. This
design also supports RTI/MTSS Tier 1 and Tier 2 delivery within the same classroom
period, reducing the need for separate intervention materials while keeping all
students working toward the same Grade [N] [subject] benchmark (RAND AIRS, 2024).
