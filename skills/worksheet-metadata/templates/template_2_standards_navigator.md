# Template 2 — Standards Navigator
# Angle   : Standards compliance as the primary value proposition
# Best For: Curriculum-aligned packs, district-adopted materials, test prep, IEP documentation
# Selects : When the worksheet is explicitly built around a named standard and the
#           teacher's primary need is documentable, gradable evidence of mastery

---

## Template Selection Criteria

Use this template when:
- The worksheet title or marketing already references a standard code
- The target teacher is a curriculum coordinator, instructional coach, or IEP writer
- The worksheet includes a rubric or scoring guide tied to a standard
- The primary teacher motivation is "I need evidence my students met [standard]"

---

## Metadata Fields

TITLE (40–60 characters)
  Pattern : [Standard Code] Worksheet: [Topic] — Grade [N]
  Example : CCSS RI.5.3 Worksheet: Text Relationships — Grade 5
  Note    : Leading the title with the standard code targets teachers who search
            by code — a high-intent, low-competition keyword pattern.

META TITLE (40–60 characters)
  Pattern : [Standard Code] [Topic] Worksheet | Grade [N]
  Example : CCSS RI.5.3 Text Relationships Worksheet | Grade 5

META DESCRIPTION (150–160 characters)
  Pattern : Standards-aligned [Standard Code] worksheet for Grade [N]. [N] tasks
            build [skill] with a clear progression to mastery. Rubric + answer key.
  Example : Standards-aligned CCSS RI.5.3 worksheet for Grade 5. 8 tasks build
            text relationship skills with a progression to mastery. Rubric included.

URL SLUG (max 75 characters, keyword-first)
  Pattern : [standard-code]-[topic]-worksheet-grade-[n]
  Example : ccss-ri-5-3-text-relationships-worksheet-grade-5
  Note    : Use hyphens in place of periods for standard codes in the slug.

TAGS (5–10 items)
  Include : standard code (no periods), grade level, subject, "standards-aligned",
            "rubric included", "formative assessment", skill name

CATEGORY
  Pattern : Grade [N] [Subject]
  Example : Grade 5 ELA
